# Contributing to Neuva

Thank you for your interest in contributing! Neuva is open source and we welcome contributions of all kinds — code, docs, bug reports, ideas, and more.

## Getting Started

1. **Fork** this repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/neuva.git`
3. **Install** dependencies: `pip install -e ".[dev]"`
4. **Create a branch**: `git checkout -b my-feature`
5. **Make your changes**
6. **Run tests**: `pytest tests/`
7. **Push** and open a **Pull Request**

## What to Work On

Check the [Issues](../../issues) tab. Labels to look for:

- `good first issue` — perfect for new contributors
- `help wanted` — we need your expertise
- `bug` — something is broken
- `enhancement` — new feature ideas
- `documentation` — improve the docs

## Code Style

- Python 3.10+
- Follow PEP 8
- Add docstrings to all functions
- Write tests for new features

## Reporting Bugs

Use the **Bug Report** issue template. Include:
- What you did
- What you expected
- What actually happened
- Your OS and Python version

## Suggesting Features

Use the **Feature Request** issue template. Explain:
- The problem you're solving
- Your proposed solution
- Example Neuva code that would use this feature

## Code of Conduct

Be kind, respectful, and welcoming. We're all here to build something great together.

Questions? Open a Discussion or reach out in the community Discord.
