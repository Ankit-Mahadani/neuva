# Neuva Logo Design Notes

## Concept
The Neuva logo should communicate two ideas simultaneously: a programming language and machine learning. The design should feel modern, technical, and approachable.

## Motif
**Neural network node combined with a code bracket.**

- Central element: a single neural network node (circle with radiating connection lines), suggesting intelligence and connectivity
- Overlaid or flanked by a pair of angle brackets `< >` or curly braces `{ }`, marking it as a programming language
- The node connections form a subtle "N" shape (for Neuva) when viewed as a whole

## Color Palette
- Primary: **Purple `#7C3AED`** — matches the existing AGPL license badge, conveys creativity and depth
- Secondary: **Blue `#3B82F6`** — matches the Python badge, suggests reliability and technology
- Accent: **Gradient** sweeping left-to-right from purple to blue on the main mark
- Background: transparent (for dark and light mode compatibility)

## Typography
- Wordmark: **"neuva"** in all-lowercase, weight 600–700
- Font style: geometric sans-serif (Inter, Geist, or similar)
- Letter spacing: slightly wide (+0.05em) for readability at small sizes
- The dot of the "i" (if applicable) or the period after the wordmark could be replaced with a small neural node

## Sizes to produce
| Variant | Dimensions | Use |
|---|---|---|
| Full logo | 400 × 120 px | README header, docs |
| Square mark | 64 × 64 px | GitHub avatar, npm/PyPI icon |
| Favicon | 32 × 32 px | Browser tab |

## Tone
Minimalist. The logo should work in one colour (monochrome) as well as the gradient. Avoid drop shadows, gradients on text, or decorative serifs. The neural node element should be clean enough to reproduce at 16 px.

## Tools suggestion
Figma or Inkscape (SVG source). Export as `logo.svg`, `logo-dark.svg`, `icon.svg`, `favicon.ico`.
